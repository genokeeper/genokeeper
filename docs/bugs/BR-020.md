- **Found:** 2026-11-02
- **Where:** `src/genokeeper/deletions/screen.py`, `classify`; against
  `src/genokeeper/calibrate/build.py`, `build_insertions`' union cut
  (`d.length >= t.min_length`).

INSurVeyor can write an insertion it could not assemble with neither `SVLEN` nor an
assembled part; `callers._event` would read it with no length, as a lower bound. If the run
kept such a call, `is_short` would not cut it, and `classify` would band it by `end - pos`,
one base: the `short` band's chance of being false, though the insertion calibration's union
cut keeps only calls of `min_length` or more, so none of that kind is in what the band
measured.

**Evidence.** On `origin/main` at 8a88393, a hand-built call that never went through a
caller step (a script, its output kept):

```
run: screen ({'GENEA': (1,)}, None) class band short length 1
calibration union cut `d.length >= min_length` keeps it: False
```

**Suggested fix (a hypothesis):** a band of its own, `unsized`, which no table measures, so
the run withholds the call's rate. Must not change: a Dysgu insertion whose length is a
bound, which keeps its length's band.

**What this evidence does not establish:** whether a run can make such a call; the call above
was built by hand, past the caller step's filter.

## Fix

Rejected: a run cannot make such a call. `deletions_only`'s INSurVeyor filter
(`callers.filter_expression`, `_INSURVEYOR_PART`) keeps a symbolic insertion only with
`|SVLEN|` of `min_length` or more, or with no `SVLEN` and an assembled part (`SVINSSEQ`) of
`min_length` or more, which `_event` reads as its length. A record with neither is cut
before the union, so `classify` never sees an INSurVeyor call of unknown length; the only
other such calls are Scramble's, which `classify` bands `mei` and the calibration judges by
position. The `unsized` band first written for this entry was removed in the same branch, as
nothing reaches it. `tests/test_deletion_callers.py::test_insurveyor_insertion_of_unknown_length_never_kept`
now holds the filter: of three incomplete assemblies (no part, `SVINSSEQ=.`, a 60 bp part)
only the last is kept, with length 60 as a bound.

Not changed: `classify`, the insertion calibration.
