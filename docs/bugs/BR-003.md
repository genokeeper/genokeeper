- **Found:** 2026-11-02
- **Where:** `src/genokeeper/deletions/screen.py`, `screen` and `is_common`.

A deletion common in gnomAD-SV (PASS, AN at least 2000, AF above 1%, reciprocal overlap at
least 0.5) is dropped as `COMMON` in every gene. The small-variant path keeps a list of BA1
exceptions for common pathogenic alleles (`resources/ba1_exceptions.tsv`); the deletion
path has none. In a recessive carrier gene a common deletion can be a real carrier allele,
and the screen would then hide it.

**Evidence.** By reading the code: `screen` returns `COMMON` before any gene is consulted,
and nothing in `deletions/` reads an exception list. Whether any listed gene is affected
needs the common records themselves, which the next section's cross-check counts.

**Suggested fix (a hypothesis):** a deletion-exceptions list beside `ba1_exceptions`, each
entry cited, applied before the `COMMON` test. Must not change: the test for every other
deletion. Alternative: no list, if no common gnomAD-SV deletion over the targets is a
pathogenic allele the screen could show.

**What this evidence does not establish:** whether any common gnomAD-SV deletion over a
listed gene's exons is a known pathogenic allele; that needs gnomAD-SV's common deletions
over the targets, checked one by one. Settled by the cross-check in the Fix section, for
gnomAD-SV v4.1.

## Fix

Rejected: no pathogenic allele the screen could show is dropped. The cross-check the entry
asked for, run on gnomAD-SV v4.1 (public data; a script over `bcftools query -R` on the
targets, its output kept), finds ten common records over the targets:


The one known pathogenic allele among them is the depth-only record over HBA2 and HBA1, by
its place, length and frequency the -α3.7 deletion (its breakpoints are depth bins); every
run already states -α3.7 and -α4.2 not covered (`sources/paralogs.py`, `NOT_COVERED`), so an
exception would show a call in a gene the run says it cannot read. SMN1's copy number is
slice 3a's, from SMNCopyNumberCaller and Parascopy. CBS's two lie in GRCh38's falsely
duplicated chr21 region, which 3c masks; RB1's is a dominant gene's at 1.9%, and ABCA3's,
MLC1's and TF's are common in a way no pathogenic allele of a rare recessive disease is.

Not changed: the `COMMON` test. If a later release adds a common record that is a carrier
allele the screen can call, the list this entry suggested is the fix, cited per entry.
