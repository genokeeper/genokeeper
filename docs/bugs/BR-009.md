- **Found:** 2026-10-28 (slice 3a's final review and re-review), carried over from the private
  archive's ledger and reproduced on `main` at `f81626d` on 2026-11-02.
- **Where:** `src/genokeeper/sources/repeats.py` (`RepeatSource._locus`'s `class` and
  `diplotype`, `_level`'s `BEYOND_FRAGMENT`), `src/genokeeper/carrier.py`
  (`GENE_LEVEL_ANSWER`) and `config/grading.toml` (`[repeat_loci]`'s `motif`).

The words a repeat statement carries can contradict its grading:

1. `claim.class` is the class of the longest allele's point estimate, while the grading reads
   its interval's upper bound: a watch whose interval straddles `normal_max` (HTT 17 and 25,
   CI 23-29) reads `class: normal` beside a reason that says "borderline, indeterminate".
2. The `BEYOND_FRAGMENT` warning ("the expansion is detected reliably, its exact size is not")
   is added whatever the kind, so it sits beside an "expanded, too few reads" watch.
3. A stage-3 gene-level finding (an expanded repeat, SMN1's one copy) answers `carrier` in
   `genokeeper genotype`, while the genome-ask skill says every non-normal SMN1 or repeat
   result is a "screening result, needs confirmation": never "you carry".
4. The motif is the catalog region's phase, not the gene's: AR's diplotype and `claim.motif`
   read "GCA 22" where the literature counts CAG (also ATXN1, ATXN2, ATXN3, ATXN7, CACNA1A,
   TBP and, as a reverse complement, C9orf72, CNBP, FGF14). The count is right.

**Evidence.** (1) and (2) by two tests on `main` at `f81626d` before any fix (pytest's
output):

```
FAILED tests/test_repeats_grading.py::test_a_watch_never_reads_class_normal
E       AssertionError: assert 'normal' == 'intermediate'
FAILED tests/test_repeats_grading.py::test_a_watch_beyond_the_fragment_claims_no_reliable_expansion
E       assert not True
```

(3) by `tests/test_carrier.py::test_repeat_carrier_at_strong_still_carrier` and
`test_smn1_finding_still_carrier`, which pass on `main` and pin `Answer.CARRIER`. (4) by
reading `config/grading.toml`'s `AR` row (`motif = "GCA"`).

**Suggested fix (a hypothesis):** (1) `class` from the interval's upper bound, the bound the
grading reads, so a non-finding still reads normal and a finding pathogenic; (2) a warning
true on every kind ("its exact size is not measured"); (3) a stage-3 finding answers
`possible_carrier`; (4) a display motif per locus, the gene-orientation motif from STRchive.
Must not change: the grading itself. Alternatives: `class` null on a watch; the warning only
on a finding; `unknown` for (3), as slice 3e's "possible" findings answer.

**What this evidence does not establish:** whether the skill has relayed any of these wrongly
to the owner.
