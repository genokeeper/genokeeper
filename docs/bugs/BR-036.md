- **Found:** 2026-11-08 (the `slice3f` calibration, from its public-sample report)
- **Where:** `src/genokeeper/calibrate/build.py`, `_phase` and `compare_phase`;
  `src/genokeeper/calibrate/slice3f.py`, `measure_phase` and `MIN_PHASE_PAIRS`.

The table trusts read-backed phase only with no cis/trans disagreement over at least 20 compared
pairs. `calibrate --only slice3f` compared one pair on HG002 PCR-free, the only library the
measure reads, so phase is untrusted though nothing disagreed. Every lab calibrates on the same
GIAB sample, so the count does not depend on the lab: as measured, no lab earns it. The run then
gives PharmCAT no read-backed phase sets (`PHASE_UNTRUSTED` in `run.inputs["pgx"]["phase"]`), and
the branch of `pipeline` that builds them is not reached. The phasing of compound-heterozygote
candidates and of APOE (`phase_pairs`) is not gated by this table.

**Evidence.** The calibration's report on the public samples, as printed by `calibrate --report`:

```
UGT1A1*28 trusted: True
phase trusted: False
 "phase": {
  "agree": 1,
  "disagree": 0
 },
```

`compare_phase` counts only neighbouring sites inside one phase set, both phased in the truth, and
`phase_sites` returns only the sites it was given: PharmCAT's heterozygous positions. The chain
SNVs that link them are not compared.

**Suggested fix:** a hypothesis. Compare every chain SNV `phase_sites` phases in PharmCAT's gene
spans, not only PharmCAT's positions, so the measure counts the same phase sets on more pairs.
`phased.json` holds PharmCAT's sites only, so that bumps `SLICE3F_STEP_VERSION` as well as
`MEASURE_VERSION`, and the `slice3f` table is rebuilt. What must not change: a
disagreement still withholds, and the run's own phasing keeps its inputs. The alternative is a
lower `MIN_PHASE_PAIRS`, which keeps the code but rests trust on one or a few pairs; leaving phase
untrusted and deleting the unreached branch is the third option.

**What this evidence does not establish:** why the count is one. The report gives only the
count: not how many sites WhatsHap phased, how many fell in the truth's benchmark or how many
phase sets held two of them. The per-site files of the calibration would settle it. It does not
show that the chain SNVs' agreement predicts the agreement at PharmCAT's positions, what PharmCAT
would call differently with phase sets, or whether the one-pair count bears on `phase_pairs`.
