- **Found:** 2026-11-02
- **Where:** `src/genokeeper/calibrate/classes.py`, `ClassTable.p_wrong`;
  `src/genokeeper/deletions/screen.py`, `warnings`; `src/genokeeper/sources/deletions.py`,
  the call's `warnings`.

`p_wrong` returns a value for any call class: the naive-Bayes product of the per-feature
shares, whether or not the calibration had a single call of that class. The table's `measured`
lists the classes each library had, but nothing a shown deletion carries tells the owner or
the `genome-ask` skill that its class had none. Likewise the rates are measured inside GIAB's
v5.0q benchmark regions, while the target exons include ones the benchmark leaves out, many
in segmental duplications; a deletion there takes the inside rate with no line saying so
(the masked feature names segmental duplications, not the benchmark).

**Evidence.** On `origin/main` at f81626d, a hand-built `DeletionTable` whose only measured
long-band class is `long:both+depth:norepeat:unmasked:nojunction` (a script, its output
kept):

```
BR-002 class seen in calibration: long:both+depth:norepeat:unmasked:nojunction p_wrong (0.625, 0.4098360655737705, 0.8064516129032259)
BR-002 class never seen: long:delly:norepeat:unmasked:nojunction p_wrong (0.625, 0.4098360655737705, 0.8064516129032259) warnings ['found by one caller (DELLY)', 'read depth does not support it']
BR-002 DeletionTable has cautions: False
```

The run reads no benchmark BED and the table records none, so no code path could say a
target lies outside it.

**Suggested fix (a hypothesis):** a warning `no calibration call of this class` read from
`measured`'s classes, and one for a deletion over a target part outside the benchmark, the
parts recorded by the calibration in the table's `extra` (the run does not need the BED).
Must not change: the `p_wrong` values themselves. Alternative: withhold `p_wrong` for an
unseen class, which hides a rate the features do support.

**What this evidence does not establish:** how many shown deletions fall in an unseen class
or outside the benchmark; that needs a count on a calibrated run.
