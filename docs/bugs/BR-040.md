- **Found:** 2026-11-09
- **Where:** `src/genokeeper/genotype/sites.py` `site_genotype`, reached from `write_target_vcf` and
  `write_pharmcat_vcf`

A `1/2` call at a position whose row lists only one of the two ALTs is written `0/1`: `_from_record`
sets `OTHER_ALLELE_WARNING` only when the listed ALT has no copy, so the guard in `site_genotype` does
not fire. Evidence: the PR 33 reviewer ran `site_genotype` on such a call and got `0/1` on each row.
How many positions of any genome this reaches has not been counted; it takes a heterozygote of two
non-reference alleles at a listed site.

**Suggested fix:** the guard's condition in `site_genotype`, which PR 33 tried and reverted. Each
step that writes through it needs its version bumped: `pgsc`, `pharmcat`, `roh_sites`, `bloodgroups`
and `admixture` (their keys do not all hold the written VCF). The alternative is to leave these
writers, and let only the research target be strict (`_prs_sites`, the state after PR 33).

**What this evidence does not establish:** whether any listed site of a real genome is such a call,
and so whether the fix is worth a rerun of the chosen scores and PharmCAT.
