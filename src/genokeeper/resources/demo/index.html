Genokeeper takes the raw reads of a 30x genome and calls them on your own machine. It grades every result twice: how likely the genotype is wrong, measured against a truth set wherever one reaches, and how strong the evidence behind the claim is. This page is its output for HG002, a public reference genome.

Ask it

Three steps put this genome in a folder you can ask questions about. The download sends nothing.

  1. Get the folder (macOS or Linux).uvx genokeeper demo
  2. Open it in your agent; in Claude Code:cd ~/genokeeper-demo && claude
  3. Ask.{{question}}
{{transcript}}

Asking is optional and goes through the agent and model you choose: what a question needs is sent to that model's provider, and with a local model nothing leaves the machine. The skill reads a local command's JSON (genokeeper query --json), so any agent can use it.

How often it is wrong

Genotypes carry a measured error rate: small variants, and the kinds of call in the table below. Polygenic scores, GWAS associations and VEP predictions carry none of their own; only the genotypes under them are measured. This run is HG002's PCR-free library, so the rows marked "same sample" are shown on the data they were measured on, and HG002 may be in DeepVariant's training data.

{{calibration}}

A clean result is not an exclusion: a variant the callers missed leaves no result. {{withheld}} Every table as the tool printed it.

What it cannot do

  • It reads only paired FASTQ from a DNBSEQ-T7 run of about 30x. Illumina reads are refused.
  • Your own run needs an Apple silicon Mac with 48 GB, about 1 TB of free disk and several days.
  • It is not a medical device. A finding is a reason to repeat the test in a clinical lab. No finding is not an all-clear. Results belong with a genetic counsellor or a clinician.
